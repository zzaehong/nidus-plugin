---
name: library
description: 사용자의 Obsidian 볼트(아카이브)에서 관련 노트를 검색해 작업에 활용할 때 사용한다. 읽기 전용.
---
볼트: `${user_config.vault_path}` (읽기 전용, 세션에 `--add-dir`로 추가됨)

- 검색: Grep/Glob으로 볼트 폴더를 직접 찾는다. 인덱스 노트(`00.index/`)가 있으면 먼저 본다. `[[위키링크]]`는 같은 이름의 `.md` 파일로 따라간다.
- 활용: 찾은 노트를 읽고 작업에 반영한다. 사용한 노트 경로를 인용한다. 관련 노트가 없으면 없다고 말한다.
- 금지: 볼트 안 파일의 생성·수정·삭제(훅으로도 차단됨). 볼트에 남기고 싶은 결과는 재홍에게 보여 주고 직접 옮기게 한다.

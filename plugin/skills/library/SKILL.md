---
name: library
description: 사용자의 Obsidian 볼트(아카이브)에서 관련 노트를 검색해 작업에 활용할 때 사용한다. 읽기 전용.
---
볼트: 세션 시작 안내의 볼트 경로(worker는 브리프로 받는다). 읽기 전용, 세션에 `--add-dir`로 추가됨.

- 검색: Grep/Glob으로 볼트 폴더를 직접 찾는다. office 폴더(세션의 작업 폴더, 볼트 안에 있을 수 있음)는 library가 아니므로 검색 결과에서 뺀다. 읽기 금지(`noread`) 경로가 볼트 안에 있으면 볼트 전체 검색은 훅이 거절하므로, 거절 메시지의 경로를 피해 하위 폴더를 지정해 검색한다. 인덱스 노트(`00.index/`)가 있으면 먼저 본다. `[[위키링크]]`는 같은 이름의 `.md` 파일로 따라간다.
- 활용: 찾은 노트를 읽고 작업에 반영한다. 사용한 노트 경로를 인용한다. 관련 노트가 없으면 없다고 말한다.
- 금지: 볼트 안 파일의 생성·수정·삭제(훅으로도 차단됨). 예외는 office 폴더뿐이다.
- 밖으로 보내지 않기: 볼트에서 읽은 내용은 웹 요청(검색어·URL)에 넣지 않는다. 공개된 식별자(종목명·티커·공개 주제어·날짜)만 쓴다. 사용자의 보유·금액·계획, 노트 문장, 사적인 이름, 파일 경로는 넣지 않는다. 결과물에 인용할 때도 결론에 필요한 만큼만 쓴다. 볼트에 남기고 싶은 결과는 사용자에게 보여 주고 직접 옮기게 한다.
